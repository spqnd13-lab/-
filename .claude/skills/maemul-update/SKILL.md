# 매물 수정 · 상태 변경

## 순서

1. **매물 번호 찾기.** 사용자가 번호(P-YSJ-28 같은)를 말하지 않았으면 찾습니다.
   `python3 tools/maemul.py find --status 전체 --q AIT센터 708호`
   후보가 여러 건이면 목록을 보여 주고 어느 것인지 확인받습니다.
2. **상태만 바꾸는 경우**
   `python3 tools/maemul.py status P-YSJ-28 거래완료`  (진행중 / 거래완료 / 보류)
3. **가격·내용을 바꾸는 경우.** 바꿀 항목만 담은 JSON을 임시 위치에 만들고 실행합니다.
   ```json
   {"deposit": 17500, "features": "남동향, 자주식 주차, 가격 조정"}
   ```
   `python3 tools/maemul.py update P-YSJ-28 /tmp/patch.json --dry-run` 으로 바뀌는 내용을 먼저 확인하고, `--dry-run` 없이 다시 실행합니다.
   - 금액은 만원 단위 숫자입니다 (1억 7,500만 → 17500).
   - 수정할 수 있는 항목과 형식은 `maemul-register` 스킬의 표와 같습니다.
4. **검사.** `python3 tools/maemul.py check` 와 `python3 .github/scripts/check_public_data.py shareal`
5. **커밋·푸시.** 커밋 메시지 예: `송도 AIT센터 102동 708호 매매가 1억 7,500만으로 조정`
6. **보고.** 무엇이 무엇으로 바뀌었는지 알려 주고, 아래 주의사항을 꼭 전합니다.

## 꼭 전해야 하는 주의사항

파일을 고치면 **홈페이지와, 매물장을 처음 여는 기기**에는 새 내용이 나옵니다. 하지만 **이미 매물장을 써 온 PC·휴대폰에는 예전 가격·상태가 그대로 남습니다** (각 기기에 저장된 연락처·메모를 지우지 않기 위해 덮어쓰지 않습니다).

그래서 수정 후에는 사용자에게 이렇게 안내합니다:
"홈페이지에는 반영했습니다. 쓰시는 PC·휴대폰의 매물장에서도 그 매물을 열어 같은 내용으로 고쳐 주세요."

## 하지 않는 것

- 매물을 파일에서 지우지 않습니다. 거래가 끝난 매물은 `거래완료`, 잠시 내린 매물은 `보류`로 바꿉니다. 삭제는 대표가 매물장 화면에서만 합니다.
- 연락처·소유자 정보·비번은 이 방법으로 넣을 수 없습니다 (도구가 거부합니다). 매물장 화면의 비공개 칸에 직접 입력하도록 안내합니다.
- 번호가 겹치는 매물(P-110, P-194)은 도구가 첫 번째 것만 고칩니다. 이 두 번호는 고치기 전에 `show`로 어떤 매물인지 확인하고, 두 번째 매물이면 사용자에게 매물장 화면에서 고쳐 달라고 안내합니다.
