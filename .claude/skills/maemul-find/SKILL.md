# 매물 찾기 · 손님 매칭

## 명령

`python3 tools/maemul.py find [조건들]`

| 조건 | 뜻 | 예 |
| --- | --- | --- |
| `--trade` | 매매 / 전세 / 월세 / 임대(월세+전세) | `--trade 임대` |
| `--type` | 매물 종류 (일부만 써도 됨) | `--type 오피스텔` |
| `--gu`, `--dong` | 구, 동 | `--gu 연수구 --dong 송도동` |
| `--max-deposit`, `--min-deposit` | 매매가·보증금 범위 (만원) | `--max-deposit 20000` (2억 이하) |
| `--max-rent` | 월세 상한 (만원) | `--max-rent 70` |
| `--q` | 검색어. 여러 개면 모두 포함 | `--q 테라스 남향` |
| `--status` | 진행중(기본) / 거래완료 / 보류 / 전체 | `--status 전체` |
| `--limit` | 보여 줄 개수 (기본 20) | `--limit 50` |

한 건을 자세히 보려면 `python3 tools/maemul.py show P-YSJ-28`.

## 손님 조건을 조건으로 바꾸기

- "매매 찾는 손님" → `--trade 매매`, "임대 찾는 손님" → `--trade 임대` (월세만이면 `--trade 월세`)
- 금액은 만원 단위로 바꿉니다. 2억 → 20000, 보증금 1천 → 1000, 월 70 → 70
- 예산에 여유를 두어 찾습니다. 손님 예산의 10% 위까지 함께 보여 주되, 예산을 넘는 매물은 "예산 초과"라고 표시합니다.
- 결과가 없으면 조건을 하나씩 넓혀(동 → 구, 금액 상한 올리기) 다시 찾고, 무엇을 넓혔는지 말합니다.

## 답하는 방법

- 가격이 낮은 순으로 3~5건을 골라 매물 번호, 매물명, 가격, 면적, 층, 특징을 정리합니다.
- 각 매물이 손님 조건의 어느 부분에 맞고 어디가 안 맞는지 한 줄로 씁니다.
- 연락처는 공개 파일에 없으므로 답에 넣을 수 없습니다. "연락처는 매물장 화면에서 그 매물을 열어 확인하세요"라고 안내합니다.
- 손님에게 추천한 매물을 기록해 두려면 `sonnim-register` 스킬의 `추천매물` 칸에 매물명을 적습니다.
