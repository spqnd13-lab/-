# 손님 등록 (매매 손님 / 임대 손님)

## 가장 중요한 규칙

손님의 이름·연락처는 **저장소의 어떤 파일에도 쓰지 않습니다.** 이 저장소는 공개이고, `shareal/data/clients.json`은 항상 `[]`입니다. 커밋 메시지, PR 설명, 코드 주석에도 쓰지 않습니다.

손님 정보는 **매물장 화면의 "붙여넣기 등록"** 으로만 들어갑니다. 이 스킬이 하는 일은 사용자가 말한 내용을 아래 양식으로 정리해 **채팅으로 돌려주는 것**입니다.

## 순서

1. 사용자가 말한 내용에서 손님 정보를 뽑습니다. **이름, 연락처, 구분** 세 가지는 꼭 필요합니다. 없으면 묻습니다.
2. 구분을 정합니다 (아래 표). 사는 사람인지 빌리는 사람인지 애매하면 묻습니다.
3. 아래 양식으로 정리해 채팅에 코드 블록으로 보여 줍니다. 모르는 칸은 줄째로 빼도 됩니다.
4. 이렇게 안내합니다:
   "매물장 → **매매 손님**(또는 임대 손님) 탭 → **붙여넣기 등록**을 눌러 위 내용을 그대로 붙여 넣고 [등록]을 누르세요."
5. 조건에 맞는 매물이 궁금해 보이면 `maemul-find` 스킬로 찾아 `추천매물` 칸에 넣어 줍니다.

직접 브라우저를 조작할 수 있고 사용자가 매물장에 로그인해 둔 경우에만, 사용자의 요청이 있으면 붙여넣기 등록까지 대신 합니다. 로그인 비밀번호는 묻지 않습니다.

## 구분

| 손님이 원하는 것 | `구분`에 적는 값 | 들어가는 탭 |
| --- | --- | --- |
| 살 집을 삼 | `매매(실거주)` | 매매 손님 |
| 투자용으로 삼 | `매매(투자)` | 매매 손님 |
| 월세로 빌림 | `임대(월세)` | 임대 손님 |
| 전세로 빌림 | `임대(전세)` | 임대 손님 |
| 가게·점포를 빌려 창업 | `상가창업(임대)` | 임대 손님 |
| 상가·사무실을 사거나 빌림 (둘 다 가능) | `상가·사무실` | 매매·임대 양쪽 |
| 분양권·입주권을 삼 | `분양권/전매` | 매매 손님 |
| 그 밖의 상담 | `기타` | 전체 손님에서만 보임 |

## 양식

```
[손님등록]
구분: 매매(실거주)
이름: 홍길동
연락처: 010-1234-5678
상태: 상담중
희망지역: 송도동
희망유형: 아파트 34평
예산: 매매 6억 이하
입주시기: 2027년 2월
추천매물: 송도 ○○아파트 101동 1203호
미팅일: 2026-11-20 14:00
미팅메모: 사무소 방문 상담
메모: 남향 선호, 초등학교 가까운 곳
```

- `상태`는 상담중 / 투어예정 / 계약완료 / 보류 중 하나입니다. 빼면 상담중으로 들어갑니다.
- `미팅일`은 `2026-11-20 14:00` 형식입니다. 시간을 빼면 오전 10시로 들어갑니다.
- 여러 명이면 손님 사이에 `---` 한 줄을 넣고 이어서 씁니다.

```
[손님등록]
구분: 매매(투자)
이름: 김매매
연락처: 010-1234-5678
예산: 매매 2억 이하
---
구분: 임대(월세)
이름: 이임대
연락처: 010-9876-5432
예산: 보증금 1000 / 월 70
```

## 알아 둘 점

- 같은 연락처의 손님이 이미 있으면 매물장이 건너뛰고 알려 줍니다.
- 손님은 **붙여 넣은 그 기기에만** 저장됩니다. 다른 직원의 기기와 나누려면 대표가 매물장 → 데이터 관리 → "보안자료 암호화 파일 만들기"를 써야 합니다. 그 비밀번호는 묻지도, 저장하지도 않습니다.
- 이미 등록된 손님의 수정·삭제는 매물장 화면에서 합니다 (삭제는 대표만).
