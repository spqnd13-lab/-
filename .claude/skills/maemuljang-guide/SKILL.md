# 매물장 사용 안내

- 주소: `https://spqnd13-lab.github.io/-/shareal/ledger.html` (홈페이지 오른쪽 위 **매물장** 버튼)
- 홈페이지는 손님이 보는 화면, 매물장은 직원이 쓰는 화면입니다.

## 계정과 권한

| 계정 | 할 수 있는 것 |
| --- | --- |
| 유수정 (대표자) | 모든 매물·손님의 연락처 열람, 등록·수정·삭제 전부 |
| 이은숙 (실장), 황규문 (과장) | 등록·수정, **본인이 등록한 매물·손님의 연락처만** 열람, 삭제 불가 |

로그인은 계정을 고른 뒤 비밀번호(PIN)를 누릅니다. PIN은 묻거나 답하지 않습니다.

## 화면 구성

| 탭 | 내용 |
| --- | --- |
| **매물장** | 전체 매물. 위쪽 버튼으로 **임대물건**(월세·전세) / **매매물건**을 나눠 봄. 상태(진행중·거래완료·보류), 지역, 검색어로 거름 |
| **매매 손님** | 매매 물건을 찾는 손님 |
| **임대 손님** | 임대(월세·전세) 물건을 찾는 손님 |
| **일정표** | 미팅·계약·잔금·만기 등 일정 달력 |

맨 위 숫자 카드 6개(안내·미팅, 계약 예정, 계약서작성, 잔금·입주, 현재 만기일, 재확인 알림)를 누르면 해당 일정으로 갑니다.

## 정보가 저장되는 곳 (가장 헷갈리는 부분)

| 정보 | 저장되는 곳 | 누가 보나 |
| --- | --- | --- |
| 매물의 공개 정보 (매물명, 주소, 가격, 면적, 특징, 사진) | 저장소 파일 → 홈페이지 | 누구나 |
| 연락처, 소유자, 비공개 메모, 손님 | **각 기기의 브라우저** | 그 기기에서 로그인한 직원만 |
| 직원끼리 나누는 비공개 자료 | 암호화 파일 `shareal/secure/private.enc.json` | 비밀번호를 아는 직원만 |

그래서:
- 새 매물을 파일에 등록하면 모든 기기의 매물장에 자동으로 나타납니다.
- 한 기기에서 입력한 연락처·손님은 **다른 기기에 자동으로 가지 않습니다.** 나누려면 대표가 매물장 → 데이터 관리 → "보안자료 암호화 파일 만들기"를 씁니다.
- 브라우저의 방문 기록·사이트 데이터를 지우면 그 기기의 연락처·손님이 사라집니다. 매물장 → 데이터 관리 → 백업을 주기적으로 받아 두도록 안내합니다. (암호화되지 않은 백업 파일은 저장소에 올리지 않습니다.)

## 어떤 일에 어떤 스킬을 쓰나

| 사용자가 하려는 일 | 스킬 |
| --- | --- |
| 새 매물 올리기 (세움터 확인 포함) | `maemul-register` |
| 가격·상태·내용 바꾸기 | `maemul-update` |
| 조건에 맞는 매물 찾기, 손님에게 추천 | `maemul-find` |
| 매매 손님 / 임대 손님 넣기 | `sonnim-register` |

## 매물장 화면에서 직접 하는 일 (파일로는 못 하는 것)

- 매물의 **연락처·소유자·비공개 메모** 입력: 매물 행의 연필 아이콘 → "고객 및 임대인 비밀 연락처" 칸
- **손님 한 명 등록**: 손님 탭 → [+ 새 손님 등록]
- **손님 여러 명 등록**: 손님 탭 → [붙여넣기 등록] (`sonnim-register` 스킬의 양식)
- **매물에 손님 연결**: 매물의 연락처 칸에 손님을 적으면 [+ 손님장]으로 손님 탭에 옮길 수 있음
- **일정 입력**: 매물 수정 창의 "3. 매물 연계 6대 스마트 일정" 칸
- **삭제**: 대표 계정만 가능
- **데이터 관리 메뉴**(백업·복원·암호화 파일)는 **PC 화면에서만** 보입니다. 휴대폰에서는 나오지 않습니다.

## 홈페이지에서 들어오는 접수

홈페이지의 매물 접수(내놓기·구하기)와 입주 서비스 견적은 사무소 휴대폰으로 **문자**가 옵니다. 매물장에 자동으로 들어오지 않으므로, 문자를 받으면 `maemul-register`(내놓기) 또는 `sonnim-register`(구하기)로 옮겨 적습니다.

## 공통 규칙

`AGENTS.md`의 규칙이 항상 우선합니다. 공개 파일에 이름·전화번호·주소(소유자)·주민번호·비번을 넣지 않습니다.
