# 운영 점검 · 담당별 할 일 뽑기

## 명령

```
python3 tools/ops_report.py              전체 리포트
python3 tools/ops_report.py --only 현아  담당 한 명 몫만 (현아 / 피클 / 클로드)
python3 tools/ops_report.py --limit 20   목록 건수 (기본 10)
python3 tools/ops_report.py --json       기계용
```

담당 구분은 `docs/ops/role-split.md` 를 따릅니다. 이 스킬은 **아무 파일도 고치지 않습니다.**

## 리포트를 읽는 법

| 항목 | 뜻 | 누가 처리 |
| --- | --- | --- |
| 민감정보 검사 실패 | 연락처·주민번호·비번이 공개 파일에 들어갔다 → **배포 중단 상태** | 즉시 대표에게 알림, 해당 값 제거 (검사는 끄지 않음) |
| 세 파일·저장키 검사 실패 | `properties.json`과 두 `properties_data.js`, 캐시 번호가 서로 다르다 | 클로드가 `maemul.py` 로 다시 맞춤 |
| 매물번호 중복 | 수정·상태 변경이 첫 번째 매물에만 걸린다 | 클로드(개발부)가 번호 정리, 정리 전까지 피클 등록부는 해당 건 보류 |
| 사진 없는 진행중 매물 | 홈페이지 "지금 볼 수 있는 매물"과 채널 콘텐츠가 다 막힌다 | 촬영은 대표·직원, 업로드는 현아(관리부) |
| 공개 소개글·특징 비어 있음 | 손님 화면에 설명이 없다 | 현아(관리부) |
| 만기 임박 / 만기일 없는 임대 매물 | 만기일이 지났거나 45일 안쪽, 또는 임대인데 만기일이 비었다 | 피클(일정관리부) — 캘린더 등록·사전 고지 |
| 30일 내 계약·잔금 일정 | 계약·잔금·미팅 날짜가 가깝다 | 피클(계약관리부) |
| 도면 없는 건물 | 진행중 매물 3건 이상인데 3D 도면이 없다 | 클로드(도면부) · `domyeon-register` |

## 답하는 방법

- 리포트를 그대로 붙이지 말고, **급한 것 3~5개**를 부서별로 묶어 먼저 말합니다. 부서 체계는 `docs/ops/role-split.md` 1-1절입니다. 전체 목록은 그 뒤에 붙입니다.
- 검사 실패와 번호 중복은 다른 무엇보다 먼저 말합니다. 배포가 멈춰 있거나 데이터가 덮어써질 수 있습니다.
- 만기 임박은 날짜와 남은 일수를 같이 적습니다. 지난 건은 "지남"으로 표시합니다.
- 숫자가 지난번과 달라졌으면 어디가 늘고 줄었는지 한 줄로 적습니다.
- 연락처는 공개 파일에 없으므로 리포트에도 없습니다. 필요하면 "매물장 화면에서 그 매물을 열어 확인하세요"라고 안내합니다.

## 고치는 일로 넘어갈 때

점검에서 나온 일을 바로 처리해도 되지만, **파일을 바꾸는 작업은 해당 스킬로 넘어가서** 합니다.
가격·상태는 `maemul-update`, 신규 등록은 `maemul-register`, 도면은 `domyeon-register`, 채널 문구는 `channel-content`.
커밋 전 `python3 tools/maemul.py check` 가 통과해야 합니다.
