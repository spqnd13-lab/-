# 매물 등록

사용자가 물건(주소·동호수)과 거래 조건(매매가 또는 보증금/월세)을 알려 주면, 세움터 건축물대장에서 확인한 내용으로 매물을 만들어 등록합니다.

## 꼭 지킬 것

- **공개 정보만** 넣습니다. 이 저장소의 파일은 누구나 볼 수 있습니다.
- 건축물대장의 **소유자 이름·주소·주민번호는 절대 넣지 않습니다.** 사용자가 보관을 원하면 파일에 쓰지 말고, 채팅으로만 정리해 주고 "매물장 화면에서 그 매물을 열어 비공개 연락처 칸에 직접 입력해 달라"고 안내합니다.
- 도어락·공동현관 비번, 연락처도 넣지 않습니다. 도구가 이런 내용을 발견하면 등록을 거부합니다. 거부되면 우회하지 말고 해당 내용을 뺍니다.
- 데이터 파일을 손으로 고치지 않습니다. 반드시 `tools/maemul.py`를 씁니다 (파일 3개와 버전 번호를 한 번에 맞춰 줍니다).

## 순서

1. **필요한 정보 확인.** 아래가 없으면 사용자에게 묻습니다.
   - 주소와 동·호수
   - 거래 형태(매매 / 전세 / 월세)와 금액
   - 담당자 (말이 없으면 유수정)
2. **세움터에서 확인.** 건축물대장(집합건물이면 전유부)에서 아래 표의 항목을 읽습니다. 대장에 없는 항목(방 개수, 방향, 관리비, 옵션)은 사용자에게 묻고, 모르면 비워 둡니다. **추측해서 채우지 않습니다.**
3. **JSON 파일 작성.** 저장소 밖 임시 위치(예: `/tmp/new.json`)에 만듭니다.
4. **미리보기.** `python3 tools/maemul.py add /tmp/new.json --dry-run` 결과를 사용자에게 보여 주고 확인받습니다.
5. **등록.** `python3 tools/maemul.py add /tmp/new.json` (담당자가 다르면 `--staff 이은숙` 또는 `--staff 황규문`)
6. **검사.** `python3 tools/maemul.py check` 와 `python3 .github/scripts/check_public_data.py shareal` 이 둘 다 통과해야 합니다.
7. **커밋·푸시.** main에 반영되면 1~2분 뒤 홈페이지와 매물장에 나타납니다. 커밋 메시지 예: `송도 ○○ 101동 1203호 월세 매물 등록 (세움터 대장 반영)`
8. **보고.** 부여된 매물 번호(예: P-YSJ-29)와 등록 내용을 알려 줍니다.

## 건축물대장 → 매물 항목

| 매물 항목 | 채우는 방법 | 예 |
| --- | --- | --- |
| `regionCity` | 인천시 / 부천시 / 서울시 / 그외 | `"인천시"` |
| `regionGu`, `regionDong` | 대지위치의 구, 동 | `"연수구"`, `"송도동"` |
| `type` | 주용도로 판단. 가능한 값: 아파트, 오피스텔, 빌라/다세대, 단독/다가구, 상가, 사무실, 상가/사무실, 지식산업센터, 근린생활시설, 사옥·통건물, 분양권, 토지/건물, 공장/창고 | `"오피스텔"` |
| `tradeType` | 매매 / 전세 / 월세 / 단기임대 | `"월세"` |
| `title` | 건물명 + 동 + 호 (필요하면 괄호로 용도) | `"송도 AIT센터 102동 708호 (오피스텔)"` |
| `address` | 도로명주소 (건물명, 지번) | `"인천광역시 연수구 송도과학로 80 (송도 AIT센터, 송도동 172-6)"` |
| `dongHo` | 동 + 호 | `"102동 708호"` |
| `deposit` | **만원 단위 숫자.** 매매가 또는 보증금. 1억 8천만 → 18000 | `18000` |
| `monthlyRent` | 월세(만원). 매매·전세는 0 | `0` |
| `maintenanceFee` | 월 관리비(만원). 모르면 0 | `8` |
| `area` | 전용면적과 공급(계약)면적. 평 = ㎡ × 0.3025, 소수 첫째 자리 | `"전용 8.8평 (29.2㎡) / 공급 21.5평 (71.12㎡)"` |
| `floor` | 해당 층 / 지상 총 층수 | `"7층 / 27층"` |
| `roomCount` | 대장에 없음. 사용자에게 확인 | `"원룸 (오픈형) / 화장실 1"` |
| `features` | 짧은 특징 (방향, 주차, 옵션 등) | `"남동향, 자주식 주차"` |
| `publicMemo` | 손님에게 보여 줄 소개글. 사용승인일, 총 층수 등 대장 내용을 포함 | |
| `photos` | 사진이 있으면 `shareal/images/`에 넣고 `"images/파일명.jpg"` | `[]` |

넣지 않는 항목: `id`(자동 부여), `contacts`(항상 비움), `createdById`·`createdByName`(담당자 옵션으로 자동), `status`(진행중으로 시작), `createdAt`(오늘 날짜).

## JSON 예

```json
{
  "regionCity": "인천시", "regionGu": "연수구", "regionDong": "송도동",
  "type": "오피스텔", "tradeType": "매매",
  "title": "송도 AIT센터 102동 708호 (오피스텔)",
  "address": "인천광역시 연수구 송도과학로 80 (송도 AIT센터, 송도동 172-6)",
  "dongHo": "102동 708호",
  "deposit": 18000, "monthlyRent": 0, "maintenanceFee": 8,
  "area": "전용 8.8평 (29.2㎡) / 공급 21.5평 (71.12㎡)",
  "floor": "7층 / 27층", "roomCount": "원룸 (오픈형) / 화장실 1",
  "features": "남동향, 자주식 주차",
  "publicMemo": "송도 AIT센터 102동 7층 오피스텔 매매. 전용 29.2㎡, 지상 27층·지하 2층, 사용승인 2024.2.2."
}
```

여러 건을 한 번에 등록하려면 JSON 배열(`[{...}, {...}]`)로 만듭니다.

## 자주 나오는 경우

- **"같은 매물이 이미 있습니다"**: 같은 매물명·동호수·거래형태가 있다는 뜻입니다. 사용자에게 알리고, 기존 매물을 고칠지(`maemul-update` 스킬) 따로 등록할지(`--allow-duplicate`) 확인합니다.
- **같은 호수를 매매와 월세로 모두 내놓는 경우**: 거래 형태별로 한 건씩 따로 등록합니다.
