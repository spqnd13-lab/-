# 채널 콘텐츠 만들기 (인천빌라당)

## 채널 성격

인천 전역 **빌라 매매**를 현관부터 방·주방·욕실까지 보여 주는 "2분 매물 투어" 계정입니다.
계정 이름은 세 채널 모두 `villadang_incheon` 으로 맞춥니다. 문의는 사무소 대표번호만 씁니다.

| 채널 | 쓰는 것 | 길이 |
| --- | --- | --- |
| 인스타 | 릴스(투어 영상) + 피드 게시물 | 캡션 3~6줄, 해시태그 10개 안팎 |
| 유튜브 | 같은 투어 영상 (쇼츠 또는 일반) | 제목 한 줄, 설명 5~8줄 |
| 당근 | 매물 글 (사진·영상 포함) | 설명 6~10줄, 해시태그 없음 |

## 1. 매물 자료 가져오기

```
python3 tools/maemul.py show P-YSJ-28          한 건
python3 tools/maemul.py find --trade 매매 --type 빌라 --gu 부평구   올릴 후보 찾기
python3 tools/ops_report.py --only 현아        사진 없는 매물 확인
```

- 올릴 후보는 **사진이 있는 진행중 매물**에서 고릅니다. 사진이 없으면 문구보다 촬영이 먼저입니다.
- 가격·면적·층·사용승인일은 **매물장과 세움터에서 확인된 값만** 씁니다. 모르면 쓰지 않습니다. 추측해서 채우지 않습니다.

## 2. 공개하면 안 되는 것 (매번 확인)

- **호수**: 층까지만 씁니다. "4층"은 되고 "401호"는 안 됩니다. 동 표기도 공개 글에서는 뺍니다.
- 도어락·공동현관 비밀번호, 임대인·임차인·고객 이름과 전화번호
- 타 중개업소·타 플랫폼 상호명, 다른 업체 워터마크가 박힌 사진·썸네일
- 확인되지 않은 사실(수익률 보장, 개발 확정, 학군 단정 등)

## 3. 문구 만드는 법

- 첫 줄에 가장 중요한 한 가지를 둡니다. 피드에서는 앞 한두 줄만 보입니다.
- 순서: 한 줄 요약 → 가격 → 면적·층·방 구조 → 특징 2~3개 → 확인된 공부 정보 → 문의.
- 숫자는 읽기 쉽게 적습니다. "1억 7,500만원", "전용 29.2㎡(8.8평)".
- 체크리스트·정보 글에는 "저장해 두세요" 한 줄을 넣습니다. 저장이 많을수록 노출이 좋습니다.
- 해시태그는 10개 안팎. 지역(#인천빌라 #부평빌라) + 거래(#빌라매매) + 상황(#신혼집 #첫집) + 계정(#인천빌라당).
- 과장·단정 표현을 쓰지 않습니다. 확인된 사실만, 평어체 설명문으로 씁니다.

## 4. 릴스 대본 양식

```
0~3초   한 줄 후킹 (지역 + 가격 + 평형)
3~15초  현관 → 거실
15~45초 방 / 주방 / 욕실
45~75초 채광·수납·주차 등 특징
75~100초 확인된 공부 정보 (사용승인일·대지지분)
~120초  문의 안내 + 저장·팔로우 요청
```

촬영 체크리스트도 같이 줍니다: 현관, 거실 전경, 방마다 한 컷, 주방, 욕실, 창밖 조망, 주차 공간, 건물 외관.

## 5. 내보내는 방법

- 채널마다 **그대로 복사해서 붙일 수 있게** 코드블록으로 하나씩 줍니다. 세 채널을 한 덩어리로 섞지 않습니다.
- 올리는 순서를 적어 줍니다(보통 릴스 → 당근 → 유튜브).
- 매물 사진 파일 경로는 `shareal/images/` 기준으로 알려 주고, 업로드는 사람이 합니다.
- 파일을 고치지 않습니다. 홈페이지에 넣을 소개글을 바꿀 때만 `maemul-update` 로 넘어갑니다.
