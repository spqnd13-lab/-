# 채널 콘텐츠 만들기 (인천빌라당 · 송도평당)

## 0. 먼저 알 것

- **제작은 클로드가 합니다.** 매물 정보는 매물장에 있으니 따로 묻지 말고 거기서 읽습니다.
- 만든 콘텐츠는 가상 오피스 **콘텐츠 보드**에 올립니다. 대표님이 [피클에 발행 요청]을 누르면
  `content-publish` 스킬의 흐름으로 피클에게 넘어갑니다.
- 채널 성격: **인천빌라당** = 인천 빌라 매매 2분 투어(주거용), **송도평당** = 송도 상가·오피스 평당 정보.
  유튜브·릴스 채널은 지금까지 해온 방식 그대로 갑니다(대표 확정).

## 1. 자료는 매물장에서 (물어보지 않는다)

```
python3 tools/content_card.py P-002 P-160 --out <작업폴더>   카드 HTML + 당근·네이버 문구
python3 tools/content_card.py P-002 --json                   문구만 JSON으로
node tools/content_card_shot.cjs <작업폴더>/cards.html <작업폴더>   카드 PNG로 굽기
python3 tools/maemul.py find --trade 매매 --type 빌라 --gu 부평구   올릴 후보 찾기
python3 tools/ops_report.py --limit 20                        사진 있는 매물·빠진 항목 확인
```

도구가 매물장에서 가격·전용면적·층·방 수·연식·특징·관리비를 읽어 채웁니다.
**없는 값은 비워 둡니다. 추측해서 채우지 않습니다.**

## 2. 공개하면 안 되는 것 (매번 확인)

- **호수**: 층까지만. "2층"은 되고 "202호"는 안 됩니다.
- **동 번호**: "신동아 102동" → "신동아". 도구가 자동으로 떼지만 결과를 한 번 봅니다.
- 도어락·공동현관 비번, 임대인·임차인·고객 이름과 전화번호
- 타 중개업소·타 플랫폼 상호, 다른 업체 워터마크가 박힌 사진
- 확인되지 않은 사실(수익률 보장, 개발 확정, 학군 단정)
- 지역 시세 통계: **만들지 않습니다.** 우리 매물만으로는 근거가 안 됩니다(대표 확정).
  비교가 필요하면 "같은 예산 우리 매물 3건" 식으로 **보유 매물 비교**만 합니다.

## 3. 포맷

### 정보 카드 (사진 없어도 되는 기본 포맷)
1080×1350. 위 30%는 가격만 크게 — 피드 미리보기에서 이 부분만 보입니다.
지역·동 → 가격 → 전용/층/방·연식 → 특징 3~4개 → 매물번호·확인 문구 → 와인색 문의 바.
쓰는 곳 세 군데: ① 인스타·당근 게시물 ② 네이버 상세설명 문구 ③ 홈페이지 소개글.

### 당근
36자 이내 한 줄 제목 + 본문(층까지만, 상용구 포함). 사진이 있으면 사진과 함께 올립니다.

### 네이버(텐컴즈)
표준폼 순서 그대로: 🏠특징 → 📍위치 → 🛤️해당층 → 📐면적 → 💰금액 → 🔥특징 →
📣금융 안내 → 🌟상호 → 💙현장광고 안내 → ✔️등록번호·주소·연락처.
`content_card.py` 가 이 순서로 뽑아 줍니다.

### 릴스 대본 (사진·영상이 있을 때)
```
0~3초   한 줄 후킹 (지역 + 가격 + 평형)
3~15초  현관 → 거실
15~45초 방 / 주방 / 욕실
45~75초 채광·수납·주차 등 특징
75~100초 확인된 공부 정보 (연식·대지지분)
~120초  문의 안내 + 저장·팔로우 요청
```
자막은 화면 아래 25% 안쪽, 첫 3초에 지역·가격·평형.

### 정보성 게시물 (사진 없을 때)
대장 읽는 법(연식·위반건축물·대지지분·전용 vs 공급·주차/관리비), 매물 접수 안내 등.
"어디서 확인하나"(세움터/정부24/관리사무소)를 한 줄씩 붙입니다. 근저당은 넣지 않습니다(대표 확정).

## 4. 만든 뒤

1. 카드·문구를 대표님께 보냅니다(이미지는 파일로).
2. 가상 오피스 **콘텐츠 보드**에 올립니다 — `office-dashboard` 스킬의 `content` 컬렉션 참고.
   상태는 완성되었으면 `편집`(발행 대기)으로 둡니다.
3. 대표님이 [피클에 발행 요청] → `content-publish` 스킬이 피클에게 넘깁니다.

## 5. 사진이 없을 때

빌라 매물에 사진이 거의 없습니다. 투어 영상이 필요한 포맷은 억지로 만들지 말고,
**촬영하면 바로 올릴 수 있는 매물 목록**(가격·면적·층이 모두 입력된 건)과
**사진 없이 올릴 수 있는 정보성 게시물**을 대신 내놓습니다.
사진이 있는 오피스텔·상가를 빌라 채널에 섞지 않습니다.

## 사진 없는 매물에 카드 붙이기 (일괄)

사진이 없는 매물은 **정보 카드**를 만들어 홈페이지 대표 사진으로 넣고, 그 카드로 당근에도 올린다.

```bash
python3 tools/card_batch.py --missing --dry      # 대상 확인
python3 tools/card_batch.py --missing            # 카드 제작 + 대표 사진 지정
python3 tools/danggeun_bulk.py --out <homebiz-ops 경로>   # 피클 전달 파일
```

- 카드는 `shareal/images/cards/card_<매물번호>.webp` (1080×1350, 약 45KB).
- 매물 데이터는 `tools/maemul.py photos` 로만 바뀐다. 손으로 고치지 않는다.
- 현장 사진이 생기면 카드 앞에 넣는다(카드는 뒤로). 카드만 있는 매물은 홈페이지에
  "정보 카드 · 사진 준비 중" 배지가 붙는다.

## 공개 표기 — 건물명과 층까지만

- 카드·당근·네이버·홈페이지 목록 제목 모두 **건물명 + 층**까지만 쓴다.
- 호수(704호), 동 번호(102동·A동·디동)는 **쓰지 않는다**. 동네 이름(도화동·청학동)은 쓴다.
- 이 규칙은 `content_card.building()` 과 홈페이지 `getPropertyDisplayTitle()` 양쪽에 들어 있다.
  새 화면을 만들면 같은 규칙을 넣는다.
- 거래완료 매물은 카드도 만들지 않고 광고도 올리지 않는다. 이미 올라가 있으면 내린다.
