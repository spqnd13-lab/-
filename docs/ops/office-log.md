## 2. 채널 안건

### 1. 매물 1건 = 정보 카드 1장 (사진 없이 지금 바로 시작) — 검토중

- 제안: 현아
- 목표(콜 유도): 사진이 없어도 당장 올려서 문의 창구를 먼저 연다
- 콘텐츠 구성:
  - 매물장에서 가격·전용면적·층·방 수·사용승인일·관리비만 뽑아 카드 한 장으로 만든다
  - 문구 서식 고정: 지역·동 → 가격 → 전용/공급 → 층·방 → 확인된 공부 정보 → 문의
  - 주 3장, 부평·연수·서구를 번갈아 올린다
  - 댓글·DM 질문은 24시간 안에 답하고, 전화로 넘어가게 짧게 답한다
- 편집 디테일:
  - 1080x1350 세로 카드. 위 30%는 가격만 크게 — 피드 미리보기에서 이 부분만 보인다
  - 가격 숫자는 굵게, 단위(만원·억)는 작게. 첫 1초에 금액이 읽혀야 한다
  - 주소는 동까지만. 호수·동 번호·도어락 정보는 절대 넣지 않는다
  - 맨 아래 와인색 고정 바에 문의 안내. 번호는 사무소 대표번호만
  - 같은 템플릿이 3장 연속되지 않게 배경색을 지역별로 3가지만 돌려 쓴다
- 검수(클로드): 사진 있는 빌라가 0건이라 지금 유일하게 돌아가는 포맷입니다. 다만 카드만 연속으로 올리면 피드가 단조로워지니 2번 안건(체크리스트)과 번갈아 편성하는 조건으로 찬성합니다.

### 2. 빌라 살 때 확인 5가지 — 실제 대장 값으로 보여주기 — 검토중

- 제안: 클로드
- 목표(콜 유도): 저장·공유가 나와 계정이 노출되고, 마지막 장에서 매물 문의로 넘어간다
- 콘텐츠 구성:
  - 사용승인일 · 대지지분 · 위반건축물 · 근저당 · 관리비/주차 다섯 가지를 5장 캐러셀로
  - 각 장에 실제 매물의 건축물대장 값을 예시로 (주소는 동까지만, 매물 특정 불가하게)
  - 마지막 장은 '대장 확인해 드립니다' 제안으로 닫는다
  - 월 2회, 같은 틀로 반복해 채널 간판 콘텐츠로 만든다
- 편집 디테일:
  - 한 장에 한 문장, 40자 이내. 읽는 데 2초 넘기지 않는다
  - 2장째 하단에 '저장해 두세요' 한 줄 — 저장이 노출을 올린다
  - 숫자·용어는 굵게, 설명은 얇게. 장마다 같은 위치에 번호 1/5
  - 마지막 장 CTA는 질문형으로: '우리 집 대지지분 궁금하시면 댓글 주세요'
  - 업로드 전 '확인된 사실만 썼는지' 한 번 더 본다. 단정 표현(무조건·보장) 금지
- 검수(현아): 대장 열람은 공부서류부에서 매일 하는 일이라 추가 부담이 없습니다. 다만 '대행'이라는 말은 중개보수와 오해될 수 있으니 '확인해 드립니다'로 바꿔 주세요.

### 3. 부평 vs 연수 빌라 매매가 비교 (월 1회) — 검토중

- 제안: 클로드
- 목표(콜 유도): 지역 검색으로 들어온 사람이 그 지역 매물을 문의하게 만든다
- 콘텐츠 구성:
  - 우리 매물장 숫자로만 비교한다 (부평 136건 · 연수 65건 보유)
  - 평균 매매가 · 평균 전용면적 · 가격대별 건수 세 가지만 보여준다
  - 끝에 '이 가격대 보유 n건' 으로 닫아 바로 문의로 연결한다
  - 숫자는 tools/ops_report.py 로 매달 1일에 뽑는다
- 편집 디테일:
  - 막대 두 개짜리 단순 그래프. 색은 브랜드 와인과 네이비 두 가지만
  - 모든 숫자 옆에 출처 한 줄: '송현아부동산 매물장 기준, 2026년 11월'
  - 외부 시세·실거래가를 단정하지 않는다. 우리 보유 매물 기준임을 명시
  - 가로 그래프는 모바일에서 글자가 겹치니 세로 막대로
- 검수(현아): 시세조사부에서 네이버·KB 숫자도 같이 보지만, 공개 콘텐츠에는 우리 매물 기준만 쓰는 게 맞습니다. 외부 시세를 단정하면 민원이 생깁니다.

### 4. 촬영 먼저 — 빌라 10건 2분 투어 제작 순서 — 검토중

- 제안: 현아
- 목표(콜 유도): 채널 본 포맷(투어 영상)이 돌아가게 재료를 만든다
- 콘텐츠 구성:
  - 사진 없는 빌라 중 가격·면적·층이 모두 입력된 10건을 먼저 고른다
  - 주 2건 촬영 — 촬영 당일에 카드 1장, 주말에 투어 영상 1편
  - 촬영 순서 고정: 외관 → 현관 → 거실 → 방 → 주방 → 욕실 → 창밖 → 주차
  - 영상은 인스타 릴스 → 유튜브 → 당근 순으로 올린다
- 편집 디테일:
  - 세로 9:16. 첫 3초에 지역·가격·평형 자막을 띄운다
  - 자막은 화면 아래 25% 안쪽에 둔다 (인스타 UI에 가려지는 영역 피하기)
  - BGM보다 설명 음성이 낫다. 말이 없으면 자막을 더 크게
  - 방 전환마다 0.3초 컷. 한 공간에 3초 이상 머물지 않는다
  - 영상 끝 3초는 고정 엔딩: 매물 번호 + 문의 안내
- 검수(클로드): 촬영 대상 10건 목록은 제가 매물장에서 바로 뽑아 드릴 수 있습니다. 주 2건이면 12월 첫 주에 첫 투어 영상이 나옵니다. 촬영 일정만 대표님이 잡아 주시면 됩니다.

### 5. 콜 기록 칸 만들기 — 어떤 콘텐츠에서 전화가 왔는지 — 검토중

- 제안: 클로드
- 목표(콜 유도): 효과 있는 콘텐츠만 남기고 나머지는 접는다
- 콘텐츠 구성:
  - 발행한 콘텐츠마다 '문의 n건'을 이 페이지에 기록한다
  - 전화 받을 때 '어디 보고 연락 주셨어요?' 한 문장을 고정 질문으로
  - 주간 점검 리포트에 콘텐츠별 문의 수를 합산해 올린다
  - 4주 뒤 문의 0건인 포맷은 접고, 문의가 나온 포맷에 집중한다
- 편집 디테일:
  - 콘텐츠 제작과 무관한 운영 안건이라 편집 요소는 없다
  - 기록 칸은 제가 이 페이지에 붙입니다 (컨펌 후 작업)
- 검수(현아): 전화 응대할 때 한 문장 더 묻는 건 어렵지 않습니다. 다만 손님이 급한 용건으로 전화한 경우에는 통화 끝에 묻는 게 자연스럽습니다.
