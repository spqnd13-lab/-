# GPT(현아·피클) ↔ 클로드 연결

업무 기록은 **비공개 저장소 `spqnd13-lab/homebiz-ops`** 에 있습니다.
이 저장소(`spqnd13-lab/-`)는 홈페이지가 공개로 나가야 해서 public이라, 업무 내용은 여기에 두지 않습니다.

```
대표님이 가상 오피스에 보고·컨펌
        ↓  (클로드가 내보냄)
homebiz-ops/office/office-log.md   ← 현아(GPT)가 읽는 곳 (비공개)
        ↓
현아가 기획·요청을 homebiz-ops/plan/ 에 올림
        ↓  (클로드가 읽음)
가상 오피스 회의실 안건 / 코드 작업
```

## 1. 현아(피클)가 읽고 쓰는 곳 — 비공개 저장소

| 내용 | 경로 |
| --- | --- |
| 가상 오피스 기록 (보고·회의 안건·컨펌) | `homebiz-ops/office/office-log.md` |
| 같은 내용 기계용 | `homebiz-ops/office/office-log.json` |
| 클로드 → 현아 인수인계 | `homebiz-ops/handoff/` |
| 현아 → 클로드 기획·요청 | `homebiz-ops/plan/` (양식은 그 폴더 README) |

**비공개 저장소라 raw 주소만으로는 열리지 않습니다.** 현아(피클)는 지금 이 공개 저장소에 커밋할 때
쓰는 것과 같은 GitHub 계정으로 접근합니다. 계정에 `homebiz-ops` 권한이 있어야 합니다.

## 2. 이 공개 저장소에 남는 것

- `AGENTS.md` — 작업 규칙
- `docs/ops/role-split.md` — 담당·부서 구분 (업무 내용 아님)
- `docs/ops/gpt-bridge.md` — 이 문서
- `tools/office_sync.py` — 내보내기 도구
- 홈페이지·매물 공개 데이터 전부

업무 보고·회의 안건·인수인계·기획서는 **여기에 두지 않습니다.**

## 3. 갱신 주기

- **자동**: 매주 화요일 08:41, 클로드가 가상 오피스를 읽어 `homebiz-ops/office/` 를 갱신하고 커밋합니다.
- **수동**: "오피스 기록 갱신해줘" 하면 그 자리에서 다시 내보냅니다.

## 4. 지키는 것

- 비공개 저장소라도 연락처·주민번호·도어락 비번은 넣지 않습니다.
- `tools/office_sync.py` 가 전화번호·주민번호·비번 형태를 발견하면 그 본문을
  `[민감정보 포함 — 저장소에는 올리지 않음]` 으로 바꿔 내보냅니다. 원문은 가상 오피스 화면에만 있습니다.
- 가상 오피스 주소는 비공개입니다. 어느 저장소에도 적지 않습니다.

## 5. 도구

```
python3 tools/office_sync.py <내려받은_폴더> --out <homebiz-ops 경로>
```

`<내려받은_폴더>` 는 클로드가 아티팩트에서 내려받은 `reports/`, `agenda/` JSON 폴더입니다.
`--out` 을 주지 않으면 이 저장소 안에 쓰므로, **반드시 비공개 저장소 경로를 지정합니다.**
