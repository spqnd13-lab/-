# 홈앤비즈 분업 지도 — 누가 무엇을 하고, 무엇이 자동으로 도는가

작성 2026-11-25. 담당이나 자동 일정이 바뀌면 **이 파일을 먼저 고칩니다.**
`tools/ops_report.py`와 `ops-check`·`channel-content` 스킬이 이 문서의 담당 구분을 그대로 씁니다.

## 3. 자동으로 도는 것

| 언제 | 무엇 | 돌리는 쪽 | 결과 |
| --- | --- | --- | --- |
| 매일 06:20 | 아침 브리핑 (캘린더·날씨·14일 내 만기·밤사이 커밋/배포) | 현아 | 대표에게 보고 |
| `main` 푸시마다 | 민감정보 검사 → 통과 시 GitHub Pages 배포 | GitHub Actions | 검사 실패 시 **배포 중단** |
| 주 1회 (화) | 운영 점검 리포트 (검사·사진·만기·번호 중복·도면 후보) | 클로드 정기작업 | 담당별 할 일 목록 |
| 주 2회 (월·목) | 신규·사진 있는 매물로 채널 게시물 초안 | 클로드 정기작업 | 바로 올릴 문구 |
| 필요할 때 | `/ops-check`, `/channel-content`, 매물 스킬 6개 | 사람이 호출 | 즉시 실행 |

정기작업은 **읽고 보고만** 합니다. 커밋·푸시·배포·광고 등록은 사람이 확인한 뒤에 합니다.

## 4. 인수인계 경계 세 곳

1. **공개 ↔ 비공개** — 공개 파일·광고에는 층까지만. 호수·도어락 비번·연락처·타 상호는 매물장(브라우저) 또는 보안 매물장에만. (`AGENTS.md` 1절)
2. **현아 → 클로드** — 기획·개선 요청은 `docs/plan/` 에 양식대로 올리고, 클로드가 그 파일을 기준으로 구현합니다. 말로만 전달하면 다음 세션에서 사라집니다.
3. **피클 ↔ 사람** — 피클은 공개 정보만 씁니다. 매물번호가 겹치면 수정·상태 변경이 첫 번째 매물에만 적용되므로, 점검 리포트의 "번호 중복"은 피클 등록 전에 정리합니다.

## 5. 자동화하지 않는 것 (확정 금지선)

- 연락처·주민번호·도어락 비번의 공개 파일 반영, `check_public_data.py`·`maemul.py check` 우회
- 암호화 비밀번호를 묻거나 저장하거나 전달하는 일
- 요청받지 않은 UI 요소 추가, AI로 만든 건물 이미지 사용
- 기기 `localStorage` 매물장과 보안 매물장(Supabase) 자동 덮어쓰기 — 변경은 대표가 수동 반영
- 도면에 미검증 치수·호실 위치, 근거 없는 계약현황 표시 ("치수 미검증" 고지 유지)
- `main` 자동 병합·배포, 피클 토큰에 비공개 DB 권한 부여
