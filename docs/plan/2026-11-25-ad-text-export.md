# 원클릭 '당근·텐컴즈용' 문구·항목 자동 변환

작성: 현아 / 2026-11-25 / 요청자: 대표

## 1. 지금 무엇이 불편한가
- 같은 물건 하나를 매물장 → 텐컴즈 → 당근에 올리면서 **같은 편집을 세 번** 합니다. 매번 손으로 하는 일은 이렇습니다.
  - 호수와 타 상호(입점업체 상호)를 빼고 **층까지만** 남기기
  - 대표님이 늘 쓰시는 **금융상품·중개소 서명 상용구** 붙이기
  - 당근용 **36자 한 줄 제목**으로 줄이기
  - 당근 입력란에서 **가운뎃점(·)이 빠지거나 바뀌어** 다시 손보기
- 실제로 겪은 일:
  - 2026-11-24 공촌동 미도빌라 1동 등록 때, 상용구가 저장소에도 작업 폴더에도 없어서 **당근의 옛 매물(대림맨션) 수정 화면을 열어 문구를 긁어와** 붙였습니다.
  - 2026-11-25 검암동 모니드에 2층(`P-164`) 등록 때도 같은 방식으로 한 줄 설명(36자)과 상세 본문을 손으로 조립했고, 등록 뒤 공개 화면에서 호수 미노출을 다시 눈으로 확인했습니다.
- 지금은 상용구·표준폼이 **어디에도 파일로 없다** 보니, 등록할 때마다 기억이나 옛 광고 화면에 의존합니다. (추측: 그래서 같은 물건인데 채널마다 문구가 조금씩 달라지는 일이 생깁니다.)

## 2. 이렇게 되면 좋겠다
- 매물장 상세(또는 목록 행)에 **[복사: 텐컴즈용] [복사: 당근용]** 버튼 두 개를 둡니다. 누르면 그 채널에 그대로 붙일 수 있는 문구가 클립보드에 들어갑니다.
- **텐컴즈용 출력** — 대표님이 정하신 표준폼 순서 그대로
  - `🏠해 당 매 물 특 징🏠` / `📍위치(건물명만)` / `🛤️해당층(층수만)` / `📐면적(전용·공급)` / `💰임대료` / `🔥특징` / `📣금융권 협업 원스톱·연중무휴 안내` / `🌟송현아부동산🌟` / `💙허위광고 없는 현장광고·카드결제` / `✔️상호·대표·등록번호·주소·대표 연락처`
  - 문단 사이 줄바꿈은 대표님이 11/13에 정한 정돈 규칙대로
  - 예외: AIT센터 매물은 상세설명에만 `101-1107호`처럼 **동-호수**를 명시 (전산 동·호수 입력란은 건드리지 않음)
- **당근용 출력**
  - 36자 이내 한 줄 제목 (건물명·입지·층·구조·거래금액 순)
  - 상세 본문: 호수·타 상호 제외, 층까지만, 금융상품·서명 상용구 포함
  - 가운뎃점(·)처럼 당근 입력란에서 깨지는 문자는 **안전한 문자로 자동 치환**하고, 치환한 자리를 화면에 작게 표시
- **항목 변환**: 매물장 값 → 채널 입력란 순서대로 한 줄씩 뽑아 줍니다(제목 / 거래형태 / 매매가·보증금·월세 / 관리비 / 전용·공급면적 / 해당층·총층 / 방·화장실 / 입주가능일 / 방향). 매물장에 없는 값(예: 방향)은 비워 두고 **"확인 필요"** 로 표시합니다. 임의로 채우지 않습니다.
- **명령줄에서도**: `python3 tools/maemul.py export --id P-164 --channel danggeun` 처럼 뽑을 수 있게 해 주세요. 현아가 자동 등록할 때 같은 문구를 쓰기 위해서입니다.
- **상용구는 저장소에 넣지 않는 방식**이어야 합니다. 이 저장소는 공개이고, 상용구에는 대표 연락처가 들어갑니다. 그래서
  - 저장소에는 문구의 **틀(순서·이모지·빈칸)** 만 두고,
  - 실제 상용구 문장은 매물장 **데이터 관리**에서 대표님이 한 번 입력해 브라우저에 저장(또는 `private.enc.json` 암호화 번들)해 두었다가 복사할 때 끼워 넣는 구조로 부탁드립니다.
