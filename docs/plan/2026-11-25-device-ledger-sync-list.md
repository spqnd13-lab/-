# 기기·보안 매물장 '미반영 변경사항' 알림 목록

작성: 현아 / 2026-11-25 / 요청자: 대표

## 1. 지금 무엇이 불편한가
- 현아(피클)는 GitHub 공개 매물장을 고칠 수 있지만, **대표님 기기(localStorage) 매물장과 보안 매물장(Supabase)에는 자동 반영이 되지 않습니다.** 자동 덮어쓰기를 하지 않는 것은 확정 원칙이라 그대로 지키고, 대신 **무엇이 아직 반영 안 됐는지**가 한 곳에 모이지 않는 게 문제입니다.
- 실제로 겪은 일:
  - 2026-11-25 청라 현대썬앤빌 더 테라스 레이크 102동 821호(`P-YSJ-22`)를 공개 매물장에서 거래완료로 바꿨지만, 대표님 기기 매물장은 아직 그대로일 수 있습니다.
  - 당근에 등록해 받은 매물번호(`P-162` = `5133742`)를 매물장에 적는 일도 지금은 말로만 남아 있습니다.
  - 이전에도 `P-253` 거래완료, `P-YSJ-18` 보증금 정정 같은 작은 변경이 **수동 반영 대기**로 밀렸습니다.
- (추측) 밀린 항목이 여러 건 쌓이면 어느 것이 반영됐고 어느 것이 안 됐는지 기억에 의존하게 되고, 기기 매물장이 옛 값으로 남아 손님 응대에 잘못된 정보가 나갈 수 있습니다.

## 2. 이렇게 되면 좋겠다
- 매물장 상단에 **"현아가 바꾼 건 (아직 미반영 N건)"** 접이식 목록을 둡니다.
  - 한 줄에: 매물ID / 매물명(층까지만) / **무엇이 바뀌었나(이전값 → 새값)** / 바뀐 날짜 / 출처(공개 매물장 커밋 · 텐컴즈 · 당근)
  - 예: `P-YSJ-22 · 청라 썬앤빌 102동 … · 상태 진행중 → 거래완료 · 2026-11-25 · 공개 매물장 52fdd03`
  - 예: `P-162 · 미도빌라 1동 … · 당근 매물번호 (없음) → 5133742 · 2026-11-24 · 당근`
- 각 줄에 **[확인] 체크**와 **[이 항목만 반영]** 버튼, 목록 위에 **[선택 항목 반영]**. 반영은 대표님이 누를 때만 **그 기기 브라우저 저장소에만** 쓰고, 반영한 줄은 '반영됨'으로 내려갑니다.
- 반영 이력을 날짜·항목·이전값/새값으로 남겨, 나중에 "이 값이 왜 바뀌었나"를 볼 수 있게 해 주세요.
- 차이 계산은 **공개 매물장(GitHub) 값과 기기 값 비교**로 하고, 연락처·도어락 비밀번호는 비교 대상에서 빼주세요(값을 읽지도 표시하지도 않기). 비공개 칸은 "비공개 값 다름" 정도만.
- 보안 매물장(Supabase)도 같은 목록을 보여주되, 반영은 대표 권한으로 **[보안 매물장에도 반영]** 을 눌렀을 때만. 자동 쓰기는 없습니다.

## 3. 어느 화면·파일인지 (아는 만큼)

- 파일: `shareal/ledger.html`, `shareal/app.js`, `shareal/data/properties.json`(읽기), `shareal/secure/private.enc.json`(형식 유지), `shareal/secure-ledger.html`, `docs/security/`(보안 매물장 문서)
