# 기획 인수인계 (현아 → 클로드)

업무 개선안·매물장 기획은 이 폴더에 **파일 하나로** 올립니다. 클로드는 여기 있는 파일을 기준으로 구현하고,
구현이 끝나면 같은 파일 맨 아래 "처리 결과"에 결과와 커밋을 적습니다.

- 파일 이름: `YYYY-MM-DD-제목.md` (예: `2026-11-26-maemuljang-photo-flow.md`)
- 한 파일에 한 주제만 담습니다. 주제가 두 개면 파일을 두 개 만듭니다.
- 연락처·주민번호·도어락 비번·고객 이름은 넣지 않습니다. 이 폴더도 공개 저장소입니다.

## 양식 (복사해서 쓰세요)

```markdown
# <제목>

작성: 현아 / <날짜> / 요청자: 대표

## 1. 지금 무엇이 불편한가
- (실제로 겪은 일 한두 줄. 추측이면 "추측"이라고 적습니다)

## 2. 이렇게 되면 좋겠다
- (화면·동작 기준으로. "빠르게" 대신 "사진 없는 매물만 모아 보는 탭")

## 3. 어느 화면·파일인지 (아는 만큼)
- 화면: 매물장 / 주택 / 상가 / 도면 / 보안 매물장 중 어디
- 파일: 아는 경우만 (`shareal/ledger.html` 등)

## 4. 지켜야 할 것
- 공개하면 안 되는 항목, 바뀌면 안 되는 기존 기능

## 5. 급한 정도
- 이번 주 / 이번 달 / 순서 오면

## 처리 결과 (클로드가 채움)
- 상태: 대기 / 진행중 / 완료 / 보류(이유)
- 커밋·PR:
- 남은 것:
```

## 처리 순서

1. 현아가 이 폴더에 파일을 올립니다.
2. 클로드가 작업 브랜치에서 구현하고 PR을 올립니다. 운영 `main` 병합은 대표 승인 뒤에 합니다.
3. 완료되면 같은 파일의 "처리 결과"를 채웁니다. 파일은 지우지 않고 기록으로 남깁니다.
