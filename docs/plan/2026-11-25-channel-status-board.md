## 2. 이렇게 되면 좋겠다
- **목록 각 행에 배지**를 붙여 주세요.
  - 텐컴즈: 매물번호 + 상태(노출중 / 네이버등록안됨 / 보관 / 노출종료 / 검수중 / 재검증중)
  - 당근: 매물번호 + 상태(게시중 / 일시정지 / 내림)
  - 대장: 전유부 열람 여부 (O / X)
  - 사진: 장수 (예: 13장) 또는 없음
- **필터**를 추가해 주세요. 여러 개를 동시에 켤 수 있게:
  - `텐컴즈 없음` / `당근 없음` / `대장 안 봄` / `사진 없음` / `광고 만료 임박(30일 내)·지남` / `ID 중복`
  - 기본값은 아무것도 켜지 않은 전체 보기 (지금 보던 화면 그대로)
- **매물ID 중복 경고**: 목록 위에 `ID 중복 N건` 배너를 띄우고, 중복된 행을 표시해 주세요. `tools/ops_report.py`가 이미 중복 ID와 사진 없는 매물을 계산하고 있으니 그 기준을 화면에서도 그대로 쓰시면 됩니다.
- **매물 상세에 채널 칸**: 텐컴즈(번호·상태·등록일·만료일), 당근(번호·상태·게시일)을 직접 입력·수정할 수 있게. 등록·만료는 캘린더 일정과도 이어지면 좋겠습니다(만료 7일 전 알림).
- **저장 위치**: 채널 번호·상태는 **공개 매물 데이터에 넣지 말고** 브라우저 매물장(localStorage)과 `private.enc.json` 암호화 번들에만 두는 쪽으로 부탁드립니다. 광고 계정과 연결되는 값이라 공개 파일에 둘 이유가 없습니다. (다른 의견이 있으면 그대로 따르겠습니다.)
