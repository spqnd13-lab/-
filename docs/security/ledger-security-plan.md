# 인천 홈앤비즈 보안 매물장 — 구현 계획 (초안)

## 검증한 현재 상태
- 정적 GitHub Pages 웹앱 `shareal/` 및 매물장 `shareal/ledger.html`, `shareal/app.js`.
- `shareal/app.js`에 클라이언트 측 PIN 로그인과 브라우저 저장소가 존재함. 이는 서버 권한 검증이 아님.
- 공개 매물 파일: `shareal/properties_data.js`, `shareal/data/properties.json`; 고객/임대인 연락처는 공개 파일에서 비워야 함.
- `shareal/secure/private.enc.json`이 공개 저장소에 존재함. 암호화 여부와 별개로 다운로드 가능한 상태이므로 공개 배포/저장소 이력 및 암호화 키 관리에 대한 별도 점검 필요.
- `AGENTS.md`와 `.github/scripts/check_public_data.py`의 공개 정보 보호 규칙을 유지할 것.
- 피클 자동 연동의 호출 경로, API 계약, 인증 방식은 **미확인**. 기존 접수 경로를 끊거나 임의 대체하지 말 것.

## 목표 아키텍처
1. 공개 웹: 공개 승인된 매물 필드만 읽음. 연락처/임차인/임대인/비공개 메모/현관 비밀번호를 포함하는 API 응답 금지.
2. 직원 매물장: 별도 인증된 API와 DB. 각 직원의 권한은 서버에서 검증.
3. 보안 DB: `listings`(업무용), `listing_private_contacts`(임대인/임차인), `staff_memberships`, `listing_assignments`, `audit_events`, `ingest_events`.
4. 피클 연동: 실제 제공 방식 확인 후 서버 수신 endpoint 또는 승인된 import adapter. 서명 검증/토큰 인증, 중복 방지 키, 재시도 안전성, 감사 기록, 비밀정보 마스킹. 브라우저나 GitHub에 피클 토큰을 두지 않음.
5. 기존 매물 번호와 3D 도면 연결을 보존. ID 변환 테이블을 통해 기존 `Plan3D` 매칭 유지.
6. 비공개 정보는 서버 측 인증·인가, TLS, 저장 시 암호화, 최소 권한, 백업/삭제 정책 적용. 로그에는 개인정보를 남기지 않음.

## 마이그레이션 단계
0. 운영 기능과 자동 접수의 실제 동작 경로를 재현하고 백업. 고객 정보는 테스트용 가짜 데이터만 사용.
1. 로그인/접근 권한을 서버 기반으로 추가. 공개 PIN 방식은 단계적으로 폐기하고 기존 PIN 교체.
2. 별도 보안 DB에 개인정보 테이블 생성. RLS는 기본 거부; 서버 API에서도 권한 재검증.
3. 기존 매물장 UI에 비공개 연락처 편집/조회 연결. 기존 매물 공개 데이터는 변경하지 않음.
4. 피클 이벤트/입력 데이터 샘플의 **개인정보 제거본**을 확보해 필드 매핑과 중복 처리 테스트.
5. 병행 검증 후 피클 연동을 새 서버로 전환. 전환 전까지 기존 경로 유지.
6. 공개 저장소의 보안자료 및 PIN 노출 이력 대응을 별도 승인된 절차로 수행. Git 이력 재작성/강제 푸시는 자동 실행하지 않음.
7. 운영 배포는 별도 승인과 회귀 테스트 이후에만 진행.

## 필수 테스트
- 비로그인/일반 고객은 비공개 연락처 조회 불가 (API 직접 호출 포함).
- 담당 직원은 허용된 매물만, 관리자는 권한 범위 내 전체 매물 조회.
- 공개 API 및 3D 페이지 응답에 개인정보 없음.
- 피클 중복 이벤트 재전송에도 중복 매물/연락처 생성 없음.
- 피클 오류가 기존 매물/연락처를 삭제하거나 덮어쓰지 않음.
- 공개 정보 검사 및 `python3 tools/maemul.py check` 통과.
- 기존 홈페이지/매물장/3D 도면/접수 기능 회귀 테스트 통과.

## 아직 필요한 정보
- 피클 서비스의 정확한 제품/관리 화면, 연동 방식(webhook/API/브라우저 자동화/기타), 데이터 스키마, 현재 연동 담당 코드 또는 서비스 설정.
- 보안 백엔드 선택(Supabase 등), 관리자/직원 계정 발급 방식, 개인정보 보존기간과 삭제 규칙.
- 기존 암호화 자료의 복구/이전 가능 여부. 비밀번호 자체는 채팅이나 저장소에 전달하지 말 것.
